## Why MetaGPT

- ICLR 2024 Oral — top 1.2%, ranked **#1** in the LLM-Agent category
- Encodes Standard Operating Procedures as multi-agent prompts — pedagogically clean
- Runs in pure Python, on a laptop, for <$0.05 — demo-friendly
- 50k+ GitHub stars, hundreds of forks
